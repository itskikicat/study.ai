# Study.AI

A responsive dark-themed study dashboard and landing page with quiz practice, flashcards, and a JARVIS-inspired study helper.

## Run locally
1. Install Node.js 18 or newer.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.

## Deploy to Render
- Build command: `npm install`
- Start command: `npm start`

## Deploy to Railway
Connect the GitHub repository. Railway detects Node.js and runs `npm start`.

## Features
- SchoolCheats-inspired marketing layout and platform tiles (original design, not a copy)
- Responsive dark UI with purple/blue accents
- Interactive sample quiz with score feedback
- Flip-style flashcards
- Demo study helper with built-in explanations

The app is for study and practice. It does not interfere with live Kahoot or Blooket games or bypass platform protections. The assistant is a demo and does not connect to an external AI service.
