# Study.AI

A responsive study dashboard with a quiz practice mode, flashcards, and a JARVIS-inspired study helper.

## Run locally
1. Install Node.js 18 or newer.
2. In this folder, run `npm install` (there are no external dependencies).
3. Run `npm start`.
4. Open `http://localhost:3000`.

## Deploy to Railway
1. Upload this project to a GitHub repository (extract the ZIP first).
2. In Railway, create a new project and choose **Deploy from GitHub repo**.
3. Select the repository. Railway detects Node.js and runs `npm start`.
4. Open the generated public domain.

## Included
- Home dashboard and responsive dark interface
- Interactive sample quiz with score feedback
- Flip-style flashcards and saved progress in browser local storage
- Study helper with sample explanations
- Custom quiz builder using your own questions

This is a learning and practice app. It does not secretly join, manipulate, or interfere with live Kahoot or Blooket games. The helper is a demo and does not connect to an external AI service.
