# Study.AI — v2.0

A responsive, original study-tool landing page inspired by the broad section flow of School Cheats: hero, supported tools, benefits, a three-step walkthrough, interactive product previews, a starter plan, and footer. It uses Study.AI branding and original copy/design rather than copying School Cheats assets or text.

## Run locally

Requires Node.js 18 or newer.

```bash
npm start
```

Open http://localhost:3000.

## Deploy to Render

- Runtime: Node
- Build command: `npm install`
- Start command: `npm start`
- Make sure `package.json` is in the repository root.

## Deploy to Railway

Connect the GitHub repository. Railway can detect the Node app and run `npm start`.

## Current functionality

- Responsive landing page and mobile navigation
- Working sample quiz with feedback and score
- Working flashcard flip and navigation
- Sample Study AI helper response (front-end demo only)

## Not connected yet

There is no user account system, database, real AI API, payment processing, or integration with live Kahoot/Blooket games. The helper is a demo until an AI provider and secure server-side API key are configured.
